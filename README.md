# 0-100 
This is a scoreboard for the [MIG game 0-100](https://playmig.com/produkt/0-100/).

The game comes with sheets of paper to keep track of the score. However, this helps you by automatically calculating your score and preventing you from wasting paper. 

*You still need the game to be able to play.*

The scoreboard is live [here](https://antonstrand.github.io/scoreboard-0-100/).
